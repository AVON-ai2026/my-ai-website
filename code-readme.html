从零到一搭建“迷你世界”主页
阶段一：放弃 Base64，使用外部图片引入
最初为了省事使用了巨长的 Base64 代码内嵌图片，导致网页加载耗时数分钟。后来果断优化为外链引入，并将 SVG 的 viewBox 严格控制在 100x100 的坐标系内。
index.html - 背景引入
<!-- 替换为外部图片，实现秒开 -->
<svg class="hotspot-svg" viewBox="0 0 100 100">
  <image href="home.png" width="100" height="100" />
</svg>
阶段二：绘制透明热区，实现精准点击
因为按钮是画在背景图里的（不是独立的 DOM 元素），我利用 SVG 的 <rect> 标签，在对应的坐标上覆盖了四个透明的矩形框，充当点击热区。
index.html - 热区绘制
<!-- 例如“作品集”热区，x/y 控制位置，width/height 控制大小 -->
<rect fill="transparent" class="hotspot-rect" 
      x="24.7" y="46.7" 
      width="22" height="10.3" />
阶段三：注入交互，悬浮高亮与页面跳转
给透明热区绑定了 onclick 跳转页面，并通过 onmouseover 和 onmouseout 事件，动态修改矩形的填充色和边框，实现了类似游戏里“选中目标”的像素悬浮反馈。
index.html - 交互逻辑
<rect fill="transparent" class="hotspot-rect" x="24.7" y="46.7" width="22" height="10.3" 
      onclick="location.href='bot.html'"
      onmouseover="this.setAttribute('fill', 'rgba(255,255,255,0.15)'); this.style.cursor='pointer';"
      onmouseout="this.setAttribute('fill', 'transparent');" 
      style="transition: all 0.2s ease;" />
